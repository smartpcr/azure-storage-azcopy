Capture current conversation context to memory.

Save the current discussion, decisions, and context to .claude/memory/ with:
- Timestamp
- Topic/feature being discussed
- Key decisions made
- Code references (file:line)
- Action items
- Related issues or PRs

Organize by:
- Date (YYYY-MM-DD)
- Category (feature, bugfix, refactor, investigation)
- Component (cmd, ste, common, e2etest)

This helps maintain context across sessions and provides searchable history of decisions and investigations.
